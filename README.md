# 🛡️ RSD-seguranca: Portfólio de Cibersegurança e Hacking Ético

Bem-vindo ao meu "diário de bordo" e portfólio profissional de Cibersegurança. Este repositório documenta a minha evolução técnica ao longo de um programa prático de 40 semanas, com foco em Linux, Redes, Programação e Segurança Ofensiva/Defensiva.

A arquitetura deste repositório está dividida entre **Estudos** (resumos teóricos e laboratórios semanais) e **Projetos** (desafios práticos que consolidam cada fase).
